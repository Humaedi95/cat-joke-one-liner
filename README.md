A tiny Python program that writes one original one-line joke about cats to
`/output/entry.txt` — an entry for the
[make.fun bounty "The One-Line Cat Joke That Lands"](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

## How to run

```sh
python3 main.py
```

This writes the joke (a single line, under 200 characters) to
`/output/entry.txt`. Set `OUTPUT_PATH` to write it somewhere else:

```sh
OUTPUT_PATH=/tmp/entry.txt python3 main.py
```
